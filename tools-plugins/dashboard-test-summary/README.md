# Dashboard Test Summary

Generate one Ze Great Dashboard test summary from the JUnit XML reports produced by your Gradle
build. The project plugin finds enabled Gradle test tasks with XML reporting, including tasks
in subprojects, and uses their configured report locations.

## Install

Apply the plugin in the root `build.gradle.kts` of each participating build. Use the published
version you want to pin.

```kotlin
plugins {
    id("com.zegreatrob.tools.dashboard-test-summary") version "<version>"
}
```

Each build produces `build/dashboard/build-test-counts.json`. The top-level build explicitly
registers included-build task dependencies and supplies those files to its own plugin:

```kotlin
dashboardTestSummary {
    includedCounts.from(layout.projectDirectory.file("build-logic/build/dashboard/build-test-counts.json"))
}

tasks.named("dashboardTestSummary") {
    dependsOn(gradle.includedBuild("build-logic").task(":dashboardTestSummaryCounts"))
}
```

This explicit wiring makes the plugin usable as a normal project plugin and lets each build use
its own project conventions and version catalog.

For a custom runner or downloaded CI shard, register its JUnit XML in the owning project's
`build.gradle.kts`. Use a task output provider for reports generated by another Gradle task.

```kotlin
dashboardTestSummary {
    reports.from(layout.projectDirectory.file("downloaded-results/junit.xml"))
}
```

## Generate the summary

```sh
./gradlew check dashboardTestSummary --continue
```

`dashboardTestSummary` schedules the test tasks that provide its input reports. With
`--continue`, Gradle can aggregate reports from failed test assertions while still returning a
failing build status. The report is written to `build/dashboard/test-summary.json` when valid
JUnit evidence is available.

The task reads `GITHUB_RUN_ID`, `GITHUB_RUN_ATTEMPT`, and `GITHUB_SHA`. To run locally, set
`-PdashboardRunId=1 -PdashboardRunAttempt=1 -PdashboardHeadSha=local`. Use `dashboardHeadSha`
to supply the PR head commit when the workflow checks out a merge commit.

Upload only `test-summary.json` to the artifact selected by your
[dashboard board configuration](https://github.com/robertfmurdock/ze-great-dashboard/blob/main/docs/board-configuration.md#github-actions-test-totals).
